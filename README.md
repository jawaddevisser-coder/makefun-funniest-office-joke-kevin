Entry for the [make.fun bounty](https://make.fun/bounty/u-kevin-the-funniest-office-joke-judged-head-to-head-3dc3233c): the funniest one-line office joke, judged head-to-head.

## The line

> The printer is the only honest employee here: it jams when it's overworked, screams when it's ignored, and still shows up every Monday.

## How it works

`main.ts` writes the joke to `/output/entry.txt`, after checking it is 1–200 characters, a single line, and not blank. Run with `node main.ts`.
